The most valuable part of this lab was troubleshooting an unexpected connectivity failure.

After verifying the routing tables and confirming router-to-router connectivity, I isolated the issue to an incorrectly configured default gateway on an end device. Correcting the configuration successfully restored connectivity.

This reinforced the importance of systematic troubleshooting and understanding why a configuration works rather than simply memorizing commands.
